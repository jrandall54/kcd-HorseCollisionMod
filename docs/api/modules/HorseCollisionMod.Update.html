Module HorseCollisionMod.Update

Update: the loop that finds collisions, and what it does with one.

The detection loop runs every TickSeconds while the player is mounted. It reads the horse's velocity, sweeps a footprint forward proportional to speed, and for every human inside it decides a tier and dispatches the reaction. Everything else in this mod is called from here.

UpdateTimer is what keeps it running, and it carries the generation guard. Re-executing the entry point builds a fresh HorseCollisionMod table, and without that guard every reload would leave another loop sweeping for collisions, all of them writing to the same tables.

SafeUpdate is wrapped in pcall by its caller: an error thrown inside a timer callback kills the loop silently, and the mod would stop working with nothing in the log to say so.

Attached to the HorseCollisionMod table created by the entry point, which pulls this file in with Script.ReloadScript.

HorseCollisionMod:TriggerCollision (npc, velocity, speed, horseEnt, playerEnt, horseWuid, sampledSpeed)
Applies the appropriate reaction for one collision.

Stands out of a charge, scores the tier from the speed, refuses a contact the horse has already been charged for, and hands the rest to ResolveImpact.

Parameters:

  • npc table victim entity
  • velocity table horse velocity vector
  • speed number speed to score the impact at, in meters per second
  • horseEnt table the player's horse entity
  • playerEnt table the player entity, player
  • horseWuid userdata WUID of the horse
  • sampledSpeed number speed read on this tick, recorded in the log so the correction for collision deceleration stays visible
HorseCollisionMod:ImpactIsNewContact (npcId, now)
Whether enough time has passed since this victim was last scored.

One contact should be one impact. The detection loop runs every 33 ms and a galloping horse takes about 150 ms to clear a person, so a single pass crosses four or five ticks and every one of them is a collision by the loop's reckoning. This asks whether the horse has already been charged for the contact it is still in, which is a different question from whether a victim can take an animation (IsVictimFlat).

The interval only has to outlast one pass. It must not approach the time a player needs to turn around and come back, because a deliberate second run is a second impact and should be scored as one.

Parameters:

  • npcId string the victim's id, as the table is keyed
  • now number the current time in milliseconds

Returns:

    boolean true when this impact should be scored
HorseCollisionMod:SafeUpdate ()
One tick of collision detection.

Bails out early unless the player is mounted and moving at least at walking pace, then tests every entity within HitRadius of the horse.

Every engine call is wrapped in pcall, because entities can be unstreamed or partially initialized at any moment and an uncaught error would kill the timer loop for the rest of the session.

HorseCollisionMod:UpdateTimer (assignedTick)
Reschedules itself every TickSeconds and runs one detection tick.

The tick number guards against duplicate loops. The entry point's load screen handler starts a new loop, and any loop whose number does not match the current one stops on its next iteration, so reloading a save leaves no stale timers running.

Parameters:

  • assignedTick number the loop generation this timer belongs to
