Module HorseCollisionMod.Tutorial

In-game tutorial guidance for horseback maneuvers.

Explains how to execute the Rear, Rear Charge, and Saddle Lean maneuvers, detailing key controls, standstill requirements, stamina drain, and crime consequences. Attached to the HorseCollisionMod table created by the entry point, which pulls this file in with Script.ReloadScript.

Info:

  • Release: 5.22.0
  • Author: jrandall54

HorseCollisionMod:FormatTutorialText (name)
Formats the tutorial text for a given maneuver, resolving configured keys.

Dynamically adapts button prompts based on whether the player is currently using a gamepad or keyboard.

Parameters:

  • name string tutorial identifier ("rear", "charge", "lean", etc.)

Returns:

    string formatted tutorial message
HorseCollisionMod:ShowTutorial (name[, force])
Displays an on-screen tutorial banner for a maneuver.

  • force boolean true to bypass settings and CVar checks (optional)
